# dsh-persona-cards · 人设卡

给 DeepSeek Harness 的模型套一张「人设卡」：按卡片设定的语气、性格和边界说话，同时保留干活的本事。

> **接手的 agent 先读 [NOTES.md](./NOTES.md)** —— 那里全是踩过的坑，照做能少走一遍弯路。

## 它为什么长在「模式」列表里

DSH 没有独立的「人设」概念，只有 **Agent 预设（preset）**——标准、PTC、极简、创造都是预设。
所以每张人设卡 = 一个 preset。副作用是卡片会和这些「模式」挤在同一个列表里，这是机制使然，不是 bug。

|---|---|---|
| 人设卡 · 小鲸鱼 | `persona-whale` | 软乎乎、话多、有点黏人的陪伴声 |

| 人设卡 · 猫系大姐姐 | `persona-neko` | 慵懒骄傲、嘴上占上风、两条路都通向她 |

## 怎么用

1. **新建一个会话**，在新建时的预设选择器里选一张卡；
2. 想让它成为默认：设置 → 预设 → 选中那张卡设为默认（之后新会话自动用它）；
3. 会话里输入 `/persona`，可以看当前用的是哪张。

已经在跑的会话不会换人设——预设是会话开始时绑定的，只有新会话（或在空白会话上重新选）才生效。

## 加一张新卡

**别手抄。** 手抄最容易漏两件事：工具行的必填 config（漏了预设直接判 broken），以及行 id 的命名约定。
用脚本生成，然后把输出贴进 `cordis.patch.yml`：

```bash
node scripts/new-card.mjs \
  --id acai \
  --name "人设卡 · 阿彩" \
  --desc "一句话介绍" \
  --prefix-file my-prefix.txt \
  --order 23
```

- `--id` 只用小写字母/数字/连字符，别带 `persona-` 前缀（脚本会加）
- 不给 `--prefix-file` 就从 stdin 读人设正文
- `--suffix-file` 可选，用来写「别忘了你是谁」这类收尾
- `--no-goal` 可选，不要 `goal` 工具时用

脚本只输出到终端，不直接改文件——先看一眼，确认没问题再贴进 `cordis.patch.yml`，然后重新安装本 bundle。

### 写人设卡的几条经验

1. **先说「怎么说话」，再说「别怎样」。** 只写禁忌，模型会变得拘谨；正面描述语气、句长、口癖效果好得多。
2. **一定要写边界段**：可以可爱、可以损，但技术结论必须准确、危险操作照样提醒。少了这句，人设会把可靠性一起吃掉。
3. **prefix 在系统提示最前面**，优先级高于后面所有指令；**suffix 在最后**，适合放「别忘了你是谁」。
4. `complete: true` 会让整份系统提示只剩这张卡（工具指引、项目规范全没了），一般别用。

## 内容边界

人设卡改的是模型的说话方式和行为倾向，所以这里有一条硬线：

- **可以做**：语气、性格、口癖、收着力的亲密动作、安全阀、主动出击、不迎合。
- **不做**：性内容、以性为目的的挑逗压制、具体身体侵犯描写、羞辱胁迫、逼人放弃自主判断。

拿「绝对安全」「两情相悦」「安全词」来包装上面那类内容，包装不改变内容性质。细节见 [NOTES.md](./NOTES.md)。

## 工具

预设只决定「有哪些工具」。三张卡默认给的是文件读写、搜索、网页、待办、目标、问答六组；
**没挂**终端、后台任务、子代理、手机控制——人设会话适合聊天和轻活。

想要更多，在卡里补对应的工具行，**先查该包的必填 config**（做法见 NOTES.md 坑二）。

## 卸载

设置 → 插件 → 移除 `@local/dsh-persona-cards`，三张卡会一起消失。
